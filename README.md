# Система управления конференциями

Веб-приложение для организации научных конференций, разработанное на ASP.NET Core.

## О проекте

Проект представляет собой backend-систему для управления участниками, материалами и организацией конференций. Реализован с использованием современных подходов .NET разработки.

## Технологии

- **Backend**: ASP.NET Core 8.0, C#
- **База данных**: Entity Framework Core, SQLite
- **Архитектура**: Clean Architecture, CQRS
- **Безопасность**: JWT, BCrypt
- **Валидация**: FluentValidation

## Основные возможности

- Регистрация и аутентификация пользователей
- Управление участниками конференций
- Загрузка и проверка материалов
- Администрирование системы
- REST API с документацией Swagger

## Архитектура

Проект разделен на четыре слоя:
- **Domain** - бизнес-логика и сущности
- **Application** - use cases и обработка запросов
- **Infrastructure** - работа с данными и внешние сервисы
- **WebAPI** - API контроллеры и DTO
